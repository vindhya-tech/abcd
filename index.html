EXPERIMENT 7: S3 → Lambda → DynamoDB
Steps:
1. Open Amazon S3 → Create bucket (enable versioning)
2. Open Amazon DynamoDB → Create table
o Name: newtable
o Partition key: unique
3. Open AWS Lambda → Create function
o Runtime: Python
o Use existing role
4. Add S3 trigger → select bucket → All object create events
5. Replace Lambda code with:
import boto3
from uuid import uuid4
def lambda_handler(event, context):
dynamodb = boto3.resource('dynamodb')
table = dynamodb.Table('newtable')
for record in event['Records']:
table.put_item(
Item={
'unique': str(uuid4()),
'Bucket': record['s3']['bucket']['name'],
'Object': record['s3']['object']['key']
}
)
👉 Click Deploy
6. Add IAM inline policy:
{ "Effect": "Allow",
"Action": "dynamodb:PutItem",
"Resource": "*"
}
7. Upload file to S3 → Check DynamoDB

Part A (SNS Email)
1. Open Amazon SNS → Create topic
2. Create subscription → Email → Confirm
3. Publish message
Part B (S3 → SNS)
1. Create S3 bucket
2. Create SNS topic
3. Add S3 event notification → SNS
4. Upload file → Email received

Part C (SQS)
1. Open Amazon SQS → Create queue
2. Send message → Receive message


Part D (Full flow)
1. Create SNS + SQS
2. Subscribe SQS to SNS
3. Add SQS policy:
{
"Effect": "Allow",
"Principal": {"Service": "sns.amazonaws.com"},
"Action": "SQS:SendMessage",
"Resource": "SQS ARN"
}

4. Create Lambda → Add SQS trigger
in role permissions add this code :
{
"Version": "2012-10-17",
"Statement": [
{
"Effect": "Allow",
"Action": [
"sqs:ReceiveMessage",
"sqs:DeleteMessage",
"sqs:GetQueueAttributes"
],
"Resource": "*"
}
]
}
5. Add Lambda code:
def lambda_handler(event, context):
for record in event['Records']:
print(record['body'])
